# Space Shooter Game - موروم 235

## لعبة Space Shooter الرائعة!

هذه لعبة فضائية 2D ممتعة مع:
- **حركة سلسة** للتحكم في المركبة الفضائية
- **نظام قتال** ضد الأعداء المختلفة
- **Power-ups** (حيات إضافية، إطلاق سريع، درع حماية)
- **مستويات صعوبة** متزايدة
- **نظام نقاط** مع أفضل النتائج
- **تأثيرات بصرية** جميلة (جزيئات، انفجارات)
- **واجهة مستخدم** واضحة

## كيفية اللعب

### التحكم
- **WASD / الأسهم**: حركة المركبة الفضائية
- **SPACE**: إطلاق النار
- **P**: إيقاف مؤقت
- **R**: إعادة بدء اللعبة بعد الخسارة
- **ESC**: خروج من اللعبة أو إيقاف مؤقت

### هدف اللعبة
- قصف الأعداء قبل أن تصل إليك
- جمّع Power-ups لتحسن قدراتك
- وصل إلى مستويات أعلى
- حاول الحصول على أعلى درجة

### أنواع الأعداء
- **حمر** (أساسيات): 100 نقطة
- **بنفسجي** (متوسطة): 200 نقطة
- **صفر** (صعبة): 300 نقطة

### أنواع Power-ups
- **أخضر**: حياة إضافية
- **أزرق**: إطلاق نار أسرع
- **ماجنتي**: درع حماية مؤقت

## كيفية التثبيت

### على Linux (Ubuntu/Debian)

```bash
# تثبيت SFML
sudo apt-get install libsfml-dev

# بناء اللعبة
mkdir build
cd build
cmake ..
make

# تشغيل اللعبة
./SpaceShooter
```

### على Windows

1. قم بتنزيل SFML من [site officiel](https://www.sfml-dev.org/)
2. افتح المشروع في Visual Studio
3. أضف paths لـ SFML
4. بناء وتشغيل

### على macOS

```bash
# تثبيت SFML
brew install sfml

# بناء اللعبة
mkdir build
cd build
cmake .. -DSFML_DIR=$(brew --prefix sfml)
make

# تشغيل اللعبة
./SpaceShooter
```
